# 💧 Watercan

A Mac habit app: water your plant every day by putting in your effort.
Track earnings against a daily minimum, keep your streak, earn coins, level up,
unlock badges, and spend coins on wishes (biscuit, snack, cream bun).

## Features
- Daily check-in with date, notes, project and event tags, watering animation
- Earnings tracker with a built-in hours × rate calculator
- Dua & tries counter, energy bar, coins, levels, badges
- Reports: daily, weekly, monthly, quarterly, yearly, filterable by project or event
- Wishes shop to spend coins on
- Daily reminder notification

## Requirements
macOS 14+, Xcode 15+ (command line tools), optionally `gh`.

## Install
```bash
./scripts/install.sh
```
Builds the app, copies it to /Applications and adds a Desktop alias.

Data is stored in `~/Library/Application Support/Watercan/data.json`.
